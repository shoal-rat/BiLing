笔灵 BiLing 1.2.0
==================

系统要求：Apple silicon Mac，macOS 26 或更新版本。

安装：
1. 右键“安装笔灵.command”，选择“打开”。
2. 等待终端显示模型校验、Qwen 排序和输入源注册全部成功。
3. 从菜单栏输入法菜单选择“笔灵”。
4. 输入 jilindaxue，确认第一候选为“吉林大学”。

笔灵、Qwen 模型、Metal 后端与 144 万条词汇已经完整包含在本目录中，
不需要 Homebrew、Xcode、联网模型或 API Key。

本构建使用 ad-hoc 代码签名，未经过 Apple 公证。若 macOS 显示开发者验证
提示，请在“系统设置 → 隐私与安全性”核对应用名称与下载来源后选择
“仍要打开”。无需、也不应关闭 Gatekeeper。

卸载：
右键“卸载笔灵.command”，选择“打开”。App 与登录启动项会移入废纸篓，
个人学习数据会保留。

项目主页：https://github.com/shoal-rat/BiLing
