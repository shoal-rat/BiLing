# 对弈 · 知音 vs Apple 拼音（第三轮：听音 r3+r4 权重平均）

**结论：知音 71.8%，Apple 拼音 64.6%，差 +7.1 个百分点，95% CI [+4.6, +9.7]。** 同一份 1119 条配对语料，出厂配置（束宽 4）。

## 这一轮做了什么

| 尝试 | 调参集（600 条）top-1 | 结论 |
|---|---|---|
| r3（基线） | 74.7% | — |
| r4：继续训练，约 70% 聊天新语料 | 73.7% | 不采用：单独 loss 更低，两耳相乘后反而差 |
| r5：按两耳相乘的目标训练（`train_poe.py`） | 69.3% | 不采用：残差式的听音不再单独校准，束搜索排序变差；把乘积重新归一化也救不回来（65.7%） |
| **r3 + r4 权重平均** | **75.8%** | **采用**：+1.2 [+0.0, +2.3]；无前文 +2.3 [+0.5, +4.7]，聊天 +2.0 [+0.3, +4.0] |

权重平均是精确的：两个 LoRA 的增量 ΔW = B·A 取平均，等价于把两组因子在秩的维度上拼接、B 各乘 ½（秩 64 → 128）。
实测每键延迟与 r3 相同（p50 70 ms vs 70 ms，同一时段测量）。
