Findings
--------
1. Context is worth +39.5 top-1 points on ambiguities that context alone can
   resolve — and ALL of it comes from the Qwen reranker. The deterministic
   engine's ranking is bit-identical with and without context: reading the
   code confirms that `PinyinEngine.candidates(for:context:)` accepts the
   context argument and never uses it. The bigram/trigram tables condition
   only on words INSIDE the composition, never on the committed text before
   the caret. That is the single clearest improvement opportunity this
   corpus exposes: seeding the lattice's sentence-start state from the last
   committed word(s) would let the 0-ms layer capture some of what currently
   costs a 25-40 ms model call.
2. Without context the full system equals engine-only overall (41.9%) —
   the model has no signal to add when the item is genuinely ambiguous, as
   designed. On mixed items it is actively worse without context (33.3% vs
   50.0%): stripped of the English left context, the reranker demotes
   English readings the frequency layer had right.
3. Remaining misses WITH full context (8): the prescriptive homophone pairs
   权力(got 权利), 须要(got 需要), 订金(got 定金), 元音(got 原因) — and every
   particle/pronoun grammar case: 得/地 (got 的), 再 (got 在), 它 (got 他).
   The 0.6B model resolves topical homophones (教师/教室, 泄漏/泄露,
   生命/声明 all correct) but not grammatical function words, where the
   signal is syntactic rather than topical.
4. Both full-system processes abort inside exit() with the known ggml Metal
   teardown assertion (ggml-metal-device.m:622) AFTER printing the complete
   report; the numbers are unaffected.
