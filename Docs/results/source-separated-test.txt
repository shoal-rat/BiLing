Why this set exists
-------------------
The hash-split derived test (Docs/results/derived-test.txt) draws dev and
test from zho_news_2020_10K. Its exact sentences are excluded from bigram
training, but two training files (zho_news_2020_100K/300K) sample the SAME
news-2020 collection, so near-duplicates of test items — the same wire story
rewritten — can sit in the training pool. This set is derived instead from
zho-cn_web_2015_30K: a collection, year, and genre that appear nowhere in
the n-gram training pool {zho_news_2007-2009_1M, zho_news_2020_100K,
zho_news_2020_300K, zho_wikipedia_2018_300K}.

Separation check (exact sentence overlap of the 30,000 web-2015 sentences
against each training file): 1M news 2007-2009: 0; 100K news 2020: 0;
300K news 2020: 1; 300K wikipedia 2018: 0; (and 0 vs the old eval source).

Reading these numbers honestly
------------------------------
1. The drop is large (-24.7 / -26.7 points top-1) but it is NOT a pure
   leakage measurement. It conflates (a) losing near-duplicate leakage and
   (b) a real domain shift: web-2015 is government budget prose, e-commerce
   and forum text, far from the news register the n-grams were trained on.
   Coverage falling 60.0% -> 26.1% shows most of the loss appears already at
   candidate GENERATION, which leakage alone cannot explain.
2. The delta the system carries over unchanged is informative: the model +
   context still add +4.4 points here (13.1 -> 17.5) vs +6.4 on the
   hash-split set — the reranker's contribution survives the shift.
3. The web-2015 crawl contains some traditional-script sentences (the Han
   regex does not distinguish scripts); items whose expected text is
   traditional are legitimate misses for a simplified-Chinese IME and
   depress the numbers slightly (e.g. expected 招標/結果 items in the miss
   list).
4. Both runs completed and printed full reports; the full-system process
   then aborted INSIDE exit() with a known ggml Metal teardown assertion
   (ggml-metal-device.m:622, llama.cpp shutdown-order issue). This happens
   after all 3381 items were scored and reported, and does not affect the
   numbers above.

The honest headline: on text the language model has genuinely never seen a
relative of, BiLing's top-1 is 17.5%, not 44.2%. The hash-split number
remains useful for tracking regressions in-domain; claims about
generalisation should cite this file.
