# 笔灵 BiLing 1.3.0

这个版本主要做四件事：更懂上下文、更省电、更稳的失败表现、更直白的文档。

## 上下文与识别

- Qwen 现在优先读取**输入框内光标前的真实文本**作为上下文（组词开始时
  读取一次，最多 600 字符，不支持的客户端自动回退）——续写半封邮件时，
  模型看到的就是那封邮件。
- 拉丁字母识别升级：约 260 条带大小写还原的精选词表（Claude、OpenAI、
  AI、GDP、xswl、yyds、Tom……）+ macOS 系统 20 万词表；合法拼音仍然
  中文优先（`ai` → 爱 第一），无真实词条的专名直接置顶
  （`openai` → OpenAI）。
- 修复 `fan` 这类短拼音被"发嗯"式单字母拼接碾压的问题。

## 性能与能耗

- Qwen 的 KV 缓存跨按键复用：上下文没变就不再解码，变了只补新增部分；
  上下文裁剪带滞回，缓存能持续命中。
- 全词表 softmax 用 Accelerate 向量化，替换每次按键上千万次的标量 exp。
- 词典查询用常驻预编译语句 + 位置记忆化 + 键区间探测提前终止，长句每键
  的 SQLite 往返从数百次降到几十次。
- 模型守护进程懒加载、10 分钟空闲自动卸载，登录与待机时几乎不占内存；
  输入法进程不再做周期健康轮询，空闲时不定时唤醒。

## 体验

- 低电量模式自动切换到苹果自带拼音；未启用时退回纯词典排序并明确提示。
- Qwen 请求失败不再清空候选：词典候选照常可用，面板只换状态徽标。
- `biling-cli` 与输入法共用同一个混分函数，打印顺序即实际输入顺序；
  新增 `--engine-only` 单测词典引擎。
- 语言模型话语权按上下文校准：冷启动词频优先，有上下文模型优先。

## 文档

- 中英 README 重写；新增拼词流水线、学习循环、方案对比双语 SVG。
- 发布示例与安装门槛改为 `jilindaxuelajixuexiao → 吉林大学垃圾学校`
  （现场整句合成，词库中并无此词条）。

## 安装

下载 `BiLing-1.3.0-macOS-arm64.zip`，解压后右键"安装笔灵.command"选择
"打开"。要求 Apple silicon、macOS 26+。构建为 ad-hoc 签名、未经公证；
遇到开发者验证提示时在"系统设置 → 隐私与安全性"确认后"仍要打开"。

## 验证

- 22 项 Swift 测试通过（新增整句示例回归、混分行为、英文词表测试）。
- 安装器在覆盖前完成模型摘要、IMKit 启动、词库、候选窗与 XPC 排序全链
  路检查。
