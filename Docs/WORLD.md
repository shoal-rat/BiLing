# 知音 · 世界观

> 伯牙鼓琴，钟子期听之。方鼓琴而志在太山，钟子期曰：“善哉乎鼓琴，巍巍乎若太山。”
> 少选之间而志在流水，钟子期又曰：“善哉乎鼓琴，汤汤乎若流水。”
> ——《吕氏春秋·本味》

## 一、母题

拼音输入法做的事情，和这个故事一模一样：**你弹出的只是声音，对方要听出你的意思。**

`shi` 是一个声音，它可能是 是、时、事、十、世、市……只有听懂了你前面在说什么，才知道你此刻要的是哪一个。
传统输入法是一张谱：同一串声音永远同一个排序。知音要做的是那个听者——钟子期。

整个软件就从这个故事里长出来：名字、名词、界面、甚至错误提示，都是这个世界里的东西。

## 二、名词表

| 世界里的名字 | 它是什么 | 为什么叫这个 |
|---|---|---|
| **知音** Zhīyīn | 输入法本身 | “知音”字面就是“懂得声音的人”。伯牙绝弦之后，这个词成了“懂你的人”的代名词 |
| **弦** | 你按下的键、正在组合的拼音，以及候选窗那根横线 | 按键就是拨弦；候选字排在一根弦上 |
| **子期** | 本机运行的微调语言模型 | 钟子期，那个听懂的人。他读前文、听拼音，写出你的意思 |
| **琴谱** | 42 万词的词库与词典解码器 | 谱是确定的、可查的；子期休息时，照谱也能弹 |
| **默契** | 本机加密的学习数据 | 弹得越久，听者越懂你 |
| **琴台** | 设置窗口 | 武汉龟山脚下的古琴台，传说伯牙与子期相遇之处 |
| **斫琴** | 模型训练流水线（`Tools/zhuoqin`） | 斫琴是制琴的手艺：选木、开料、上弦。这里是选语料、造样本、训练、导出 |
| **调音** | 命令行工具 `tiaoyin` | 上台之前先调音：转写、评测、测速都在这里 |

| **印** | 候选窗末尾的小印章 | “听”字印：这份候选是子期听出来的；“谱”字印：子期未到，琴谱独奏 |
| **新词包** | 网络流行语、中英混杂、近年新词的训练数据 | 琴谱旧了要添新曲 |

### 子期的状态

| 状态 | 说法 | 实际含义 |
|---|---|---|
| 就绪 | **子期在听** | 模型已载入，每个按键都会听 |
| 加载中 | **子期将至** | 正在载入模型（约 0.5 秒） |
| 闲置释放 | **子期小憩** | 长时间不打字，模型已从内存释放；下一个按键唤醒 |
| 不可用 / 关闭 | **独奏** | 只有琴谱在弹：模型文件缺失、用户关闭、或低电量模式 |

### 听法（能耗档位）

- **细听**：束宽 6，更准；
- **轻听**：束宽 3，更省电。

## 三、视觉语言：青绿山水

颜色取自青绿山水的矿物颜料，画在宣纸上：

| 名 | 色值 | 用在哪里 |
|---|---|---|
| 宣 | `#F6F1E7` | 候选窗与琴台的底色 |
| 墨 | `#232629` | 候选字 |
| 石青 | `#2F6577` | 弦（闲置时的横线）、选中态 |
| 石绿 | `#3E8A6E` | 夜山配色下的弦 |
| 朱砂 | `#B6432F` | 被拨动的那一段弦、徽点、印章 |
| 赭石 | `#9A6D48` | 候选编号（徽） |
| 夜山 | `#16191D` | 深色模式底色 |
| 月白 | `#E4E8E6` | 深色模式文字 |

**候选窗「弦」**

```
 ①吉林大学垃圾学校  2吉林大学  3吉林  4急  5及  6集  7吉        ‹›  [听]
 ━━━━━━━━━━━━━━━━━──────────────────────────────────────────────────
   ↑ 朱砂：被拨动的那段弦                         ↑ 石青：静止的弦
```

- 候选不画方框、不画背景块，排在一根细弦上；高亮项下面那一段弦变成朱砂色并加粗——那是被拨动的弦。
- 子期还没回话时，弦会轻轻颤动（最多约一秒，振幅衰减）；回话后静止。**空闲时界面从不动画。**
- 字体三种：清雅（苹方）、墨韵（宋体）、楷书（楷体）。

**图标**：古琴的弦横贯宣纸，中间一根弦隆起为山（高山），又化作水波流出（流水），右下一方朱文印“知音”。

## 四、交互里的世界

- Shift 轻点切换中 / 英，光标旁浮现一方小印：“中”或“英”。
- 菜单栏的输入法菜单里，第一行是 **琴台…**，然后是子期当下的状态，最后是 **独奏（暂歇子期）**。
- 琴台五间：**高山流水**（首页与故事）、**指法**（按键与标点）、**子期**（模型与能耗）、**默契**（你的用词记忆，可搜索、单删、全忘、导出）、**山水**（纸色、字体、字号，实时预览候选窗）。

## 五、为什么要有一个世界

一个输入法每天被看上千次。名字、颜色、动效如果各说各话，它就只是一个工具；如果它们都来自同一个故事，它就有了性格。
知音的性格是：**安静、懂你、不打扰**——听者从不抢话。所以界面没有多余的装饰，模型只在你按键时工作，空闲时连一个像素都不动。
