# 安全政策 / Security Policy

## 支持版本

安全修复仅面向最新 GitHub Release。升级前可保留安装器自动创建的上一版本
备份。

## 报告漏洞

请不要把未修复的敏感漏洞发布为公开 Issue。使用 GitHub 仓库的
**Security → Report a vulnerability** 私密报告入口，并提供：

- 受影响版本与 macOS 版本；
- 可重复的最小步骤；
- 是否涉及 XPC 客户端校验、学习数据、Keychain、Secure Event Input 或模型
  文件完整性；
- 你建议的披露时间。

请勿在报告中附带真实密码、私人输入历史或其他敏感数据。

## English

Security fixes target the latest GitHub release. Do not file an unresolved,
sensitive vulnerability as a public issue. Use the repository's private
**Security → Report a vulnerability** flow and include the affected version,
macOS version, minimal reproduction, impacted trust boundary, and proposed
disclosure timeline. Never attach real passwords or private typing history.
